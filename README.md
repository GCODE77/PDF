# PDF 공작소

PDF를 열고 · 고치고 · 서명하고 · 변환하고 · 줄이는 앱. 폰과 PC에서 같은 화면으로 쓰는 웹앱(PWA)이자 Windows 설치 앱입니다.
**모든 처리는 기기 안에서만 이루어집니다.** 파일이 서버로 올라가지 않고, 한 번 열어 두면 오프라인에서도 동작합니다.

- 웹 주소: https://gcode77.github.io/PDF
- 현재 버전: **1.3.2**

## 설치 · 실행

| 환경 | 방법 |
|---|---|
| **Windows (가장 쉬움)** | [Releases](https://github.com/GCODE77/PDF/releases/latest)의 `PDF-Gongjakso-Setup.exe`를 받아 더블클릭. 바탕화면·시작 메뉴 아이콘이 생기고, PDF 파일의 「연결 프로그램」으로도 쓸 수 있습니다. |
| 폰 · PC (웹앱 설치) | 위 웹 주소를 열고 앱 안의 「앱 설치」 버튼(또는 브라우저 메뉴의 「앱 설치 / 홈 화면에 추가」)을 누릅니다. 아이폰은 사파리의 공유 → 「홈 화면에 추가」. |
| 설치 없이 PC에서 | Releases의 `PDF-gongjakso-offline.zip`을 풀고 `실행.bat` 더블클릭 (파이썬 불필요) |

> 설치 파일은 코드 서명이 없어서 처음 실행할 때 Windows 보호 화면이 뜰 수 있습니다. 「추가 정보 → 실행」을 누르세요.
> 웹앱 설치와 오프라인 기능은 HTTPS 주소에서만 동작합니다.

## 업데이트

새 버전이 나오면 앱 위쪽에 알림 막대가 뜹니다(설치 앱은 Windows 알림창도 함께).

- 실행 3초 후, 6시간마다, 오래 두었다가 돌아왔을 때 자동으로 확인합니다. 메뉴의 **도움말 → 업데이트 확인**으로 직접 확인할 수도 있습니다.
- **설치 앱**: 「지금 업데이트」를 누르면 새 설치 파일을 내려받아 자동으로 설치하고 다시 실행합니다.
- **웹앱(폰·PC)**: 「지금 업데이트」를 누르면 바로 새 버전으로 새로고침됩니다.
- 「나중에」를 누르면 하루 동안은 같은 버전으로 다시 알리지 않습니다.
- 버전 정보는 이 저장소의 `version.json`(웹 주소로 배포)에서 읽습니다. 업데이트 내려받기는 이 저장소의 릴리스 주소만 허용합니다.

## 기능

도구 패널은 Adobe Acrobat 구성(PDF 파일변환 · PDF 편집 · PDF 만들기 · 주석 · 파일 결합 · 페이지 구성 · PDF 압축 · 교정 · 양식 만들기 · 전자 서명 요청 · 채우기 및 서명 · 주석 요청하기 · 추가 도구)을 따릅니다. 위쪽 검색창으로 도구를 바로 찾을 수 있습니다.

- **PDF 편집(본문 수정)**: 원래 PDF에 있는 글자를 눌러 그 자리에서 고치거나 지웁니다. 원본 글자는 PDF 내부에서 실제로 제거되어 검색·복사에도 남지 않습니다. 고친 뒤(Enter 확정) 나타나는 서식 막대에서 글꼴(무료 글꼴 38종: 고딕·명조·제목체·손글씨·고정폭·영문, 또는 내 글꼴 파일)·크기·굵게·기울임·밑줄·취소선·색을 바꾸고, 끌어서 위치를 옮깁니다. 글자는 그대로 두고 서식만 바꾸려면 글자를 누른 뒤 Enter를 누르세요. 명조·바탕 계열 글자는 처음부터 나눔명조로 들어갑니다.
- **변환 (PDF → 다른 형식)**: Word(DOCX) · PowerPoint(PPTX) · 엑셀(XLSX) · 텍스트(TXT) · 웹 페이지(HTML) · 마크다운(MD) · 표만 CSV · 사진(PNG/JPG) · PDF 안의 이미지 추출. 글꼴·크기·색·정렬, 선이 있는 표(합친 칸 포함)와 선이 없는 정렬 표, 그림을 인식해 옮깁니다. 스캔 문서는 OCR 옵션으로 글자를 만듭니다.
- **PDF 만들기**: 사진 → PDF(순서 지정·카메라) · 빈 문서 · 글(TXT/MD) → PDF · 클립보드 이미지 → PDF
- **주석**: 메모(스티커) · 형광펜 · 밑줄 · 취소선 · 펜 · 도형(사각형·원·선·화살표) · 스탬프 · 텍스트 · 이미지 삽입 · 지우개
- **서명 · 채우기**: 직접 그리기(색·굵기) / 이름 입력(내장 손글씨·필기체 글꼴, 내 컴퓨터 글꼴, 글꼴 파일 불러오기, 굵게·기울임·색) / 서명 사진. 넣은 뒤 모서리 점으로 크기, 끌어서 위치 조절. 기기에 저장해 재사용. 문서의 입력 양식(AcroForm) 채우기와 고정.
- **교정(영구 삭제)**: 검은 상자로 가릴 영역을 표시하거나 단어·주민번호·전화번호·이메일·카드번호를 검색해 한꺼번에 표시한 뒤 「교정 적용」. 「그림으로 바꿔 완전 삭제」(권장) 또는 「글자만 제거」를 고릅니다.
- **양식 만들기**: 텍스트 필드 · 체크박스 · 라디오 · 드롭다운 · 서명란을 그려 넣으면 저장 시 다른 PDF 프로그램에서도 입력되는 진짜 양식이 됩니다.
- **전자 서명 요청 · 주석 요청**: 서버 없이 파일을 주고받는 방식입니다. 서명란을 넣고 공유(또는 메일 작성 창)로 보내면, 받는 사람이 PDF 공작소로 서명·의견을 넣어 돌려줍니다. 진행 현황 추적은 지원하지 않습니다.
- **페이지**: 끌어서 순서 변경, 삭제, 개별 회전, 복제, 빈 페이지 추가, 선택 추출, PDF 삽입, 파일 결합, 쪽 나누기(N쪽마다·범위·한 쪽씩), 쪽 자르기, 머리글·바닥글·쪽 번호
- **압축** 가벼운 최적화 / 균형 / 최대 압축 · **보안** 열기 비밀번호 + 인쇄·복사·편집 제한 · **워터마크** 추가/제거 · **배경 정리** · **문자 인식(OCR)** · **문서 속성** · **인쇄**
- **검색**: 문서 전체 검색(결과 목록·강조 표시), 목차(북마크) 보기

## 화면 구성 (Adobe Acrobat 구성을 참고)

- **홈**: 큰 「PDF 열기」 버튼, 왼쪽 메뉴(최근 · 별표 표시된 파일 · 파일 · 도구), 최근 파일 목록(썸네일·열린 시간·크기, 목록/격자 보기), 도구 카드, 위쪽 검색창(파일·도구 검색)
- **문서 탭**: 여러 PDF를 동시에 엽니다(최대 12개). 탭을 끌어서 순서를 바꾸고, ×·가운데 버튼·Ctrl+W로 닫습니다. 저장하지 않은 탭에는 ● 표시가 붙습니다.
- **메뉴 막대(PC)**: 파일 · 편집 · 보기 · 서명 · 창 · 도움말, 하위 메뉴와 단축키 표시.
  - 보기 → 보기 회전 / 페이지 탐색 / **페이지 표시(한 페이지 · 스크롤 · 두 페이지 · 두 페이지 스크롤 · 네 페이지(2×2) · 네 페이지 스크롤, 페이지 사이 간격, 표지 페이지)** / 확대·축소 / 도구 / 표시·숨기기 / 표시 테마(밝게·어둡게·시스템) / 읽기 모드(Ctrl+H) / 전체 화면(Ctrl+L) / 소리내어 읽기 / 자동 스크롤(Shift+Ctrl+H)
- **편집 화면**: 위쪽 도구 막대, 왼쪽 페이지·목차·검색 패널, 오른쪽 도구 목록(검색·펼침), 아래쪽 확대/축소 막대. 오른쪽 위의 파란 **저장** 버튼은 항상 같은 자리에 있고, 편집 내용은 저장할 때 PDF에 합쳐집니다.
- **폰**: 아래 메뉴(페이지·검색·도구·홈), 두 손가락 확대/축소, 도구 목록은 아래에서 올라오는 시트
- **최근 파일·별표**: 이 기기(브라우저 저장소)에만 저장됩니다. 80MB가 넘는 파일은 목록에만 남고 다시 열 때 파일을 새로 고릅니다. 별표는 목록 정리 때 지워지지 않습니다.
- **기본 PDF 앱으로 설정(Windows)**: 설치 앱은 실행할 때 Windows 「기본 앱」 목록과 PDF 「연결 프로그램」에 자동으로 등록됩니다(사용자 영역, 관리자 권한 불필요). Windows 정책상 프로그램이 기본 앱을 마음대로 바꿀 수 없어, 도움말 → 「기본 PDF 앱으로 설정」의 안내(또는 Windows 기본 앱 설정 열기)에 따라 한 번만 직접 고르면 됩니다.

## 알아둘 점

- 「균형·최대 압축」, 「배경 정리」, 암호 해제는 페이지를 이미지로 다시 만들기 때문에 글자 선택·검색이 사라집니다. 필요하면 이어서 「문자 인식(OCR)」을 실행하세요.
- 다른 프로그램이 문서 내용에 합쳐 넣은 워터마크는 자동 제거가 어렵습니다. 「지우개」로 가린 뒤 「모든 페이지에 적용」을 쓰세요.
- 페이지 복제·재구성 시 문서의 입력 양식(AcroForm)과 북마크는 유지되지 않을 수 있습니다.
- Word·PPT·엑셀 변환은 PDF의 글꼴·표·그림을 분석해 옮기지만, 복잡한 편집 디자인·다단·선이 없는 복잡한 표는 원본과 다를 수 있습니다. 원본 글꼴이 PC에 없으면 Word가 다른 글꼴로 바꿔 보여줍니다.
- 본문 수정은 한 줄 단위로 고칩니다. 원래 PDF 글꼴 그대로가 아니라 내장 글꼴로 다시 그리므로 폭이 조금 다를 수 있고, 글자를 고친 줄 뒤의 배경이 그림이면 흰 사각형이 보일 수 있습니다(되돌리기로 취소).
- 「교정」은 「그림으로 바꿔 완전 삭제」를 고르면 해당 쪽의 글자 선택이 사라집니다(필요하면 OCR).
- 영문 전용 글꼴(Roboto, Lato 등)로 한글을 쓰면 한글 부분은 자동으로 기본 글꼴(Noto Sans KR)로 이어서 그려집니다. 글꼴 파일은 선택할 때 한 번 내려받고(설치 앱은 모두 들어 있음) 이후 캐시됩니다.
- 서명 글꼴 중 한글·영문 손글씨는 선택할 때 한 번 내려받고(수 MB), 이후 캐시됩니다. 영문 필기체 글꼴은 한글을 표시하지 못합니다.

## 새 버전 내는 방법

1. 버전 번호를 올립니다: `js/update.js`의 `VERSION`, `version.json`의 `version`·`notes`, `desktop/package.json`의 `version`.
2. 코드를 `main`에 푸시합니다(GitHub Pages로 웹앱이 자동 배포되고, `sw.js`의 캐시 이름 `pdfgongjakso-vN`도 올려 두면 오래된 캐시가 정리됩니다).
3. `python desktop/build.py`로 설치 파일(`PDF-Gongjakso-Setup.exe`)을 만듭니다. 한글 경로 문제를 피하려고 임시 영문 폴더에서 빌드하며, Node.js와 Python(Pillow)이 필요합니다.
4. 새 태그로 GitHub 릴리스를 만들고 설치 파일과 ZIP을 올립니다. 이미 설치된 앱들이 다음 확인 때 알림을 받습니다.
