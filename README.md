# PDF 공작소

PDF를 열고 · 고치고 · 서명하고 · 변환하고 · 줄이는 앱. 폰과 PC에서 같은 화면으로 쓰는 웹앱(PWA)입니다.
**모든 처리는 기기 안(브라우저)에서만 이루어집니다.** 파일이 서버로 올라가지 않고, 한 번 열어 두면 오프라인에서도 동작합니다.

## 실행

| 환경 | 방법 |
|---|---|
| PC (지금 바로) | `실행.bat` 더블클릭 → 브라우저에서 http://localhost:8772 열림 (Python 필요) |
| 폰 + PC 모두 | 이 폴더를 HTTPS 호스팅에 올리면 같은 주소로 접속하고 「홈 화면에 추가 / 앱 설치」 가능 (Netlify Drop, GitHub Pages, Cloudflare Pages 등 무료) |

> 폰에서 설치(PWA)·오프라인 기능은 HTTPS 주소에서만 켜집니다. 올리는 것은 이 앱 파일뿐이고, 사용자의 PDF는 올라가지 않습니다.

## 기능

- **편집·주석**: 텍스트 추가, 메모(스티커), 형광펜, 펜(손글씨), 이미지 삽입, 스탬프(승인됨·초안 등), 지우개(영역 가리기 → 모든 페이지 적용)
- **서명**: 직접 그리기 / 이름 입력 / 서명 사진 올리기(흰 배경 자동 제거), 기기에 저장해 재사용
- **페이지**: 순서 변경(끌어서 이동), 삭제, 개별 회전, 복제, 빈 페이지 추가, 선택 추출, PDF 삽입, 파일 결합
- **변환**: PDF → 사진(PNG/JPG, 여러 장은 ZIP) · 텍스트(TXT) · Word(DOCX), 사진 → PDF(여러 장·카메라 촬영)
- **압축**: 가벼운 최적화 / 균형 / 최대 압축
- **보안**: 열기 비밀번호 + 인쇄·복사·편집 제한. 암호 PDF는 열 때 비밀번호를 입력하면 해제된 사본으로 열림
- **워터마크**: 글자·로고, 가운데/바둑판 · 이 앱이 넣은 워터마크와 표준 워터마크 주석 자동 제거
- **배경 정리**: 스캔 문서의 그림자·누런 배경 제거(컬러/회색조/흑백), 미리보기 제공
- **문자 인식(OCR)**: 한국어+영어, 검색 가능한 PDF 만들기 / 글자만 추출
- **검색**: 문서 전체 빠른 검색(결과 목록·강조 표시), 목차(북마크) 보기

## 사용 흐름 (Adobe Acrobat 구성을 참고)

- 홈: 큰 「PDF 열기」 버튼 + 도구 카드(아이콘·설명·버튼). 카드를 누르면 파일 선택 → 바로 해당 도구 실행
- 편집 화면: 위쪽 도구 막대, 왼쪽 페이지·목차·검색 패널, 오른쪽 도구 목록, 아래쪽 확대/축소 막대
- **저장** 버튼(오른쪽 위, 파란색)이 항상 같은 자리에 있습니다. 편집 내용은 저장할 때 PDF에 합쳐집니다.
- 실행 취소 Ctrl+Z / 다시 Ctrl+Y / 검색 Ctrl+F / 저장 Ctrl+S
- 폰: 아래 메뉴(페이지·검색·도구·홈), 두 손가락으로 확대/축소, 도구 목록은 아래에서 올라오는 시트

## 알아둘 점

- 「균형·최대 압축」, 「배경 정리」, 암호 해제는 페이지를 이미지로 다시 만들기 때문에 글자 선택·검색이 사라집니다. 필요하면 이어서 「문자 인식(OCR)」을 실행하세요.
- 다른 프로그램이 문서 내용에 합쳐 넣은 워터마크는 자동 제거가 어렵습니다. 「지우개」로 가린 뒤 「모든 페이지에 적용」을 쓰세요.
- 페이지 복제·재구성 시 문서의 입력 양식(AcroForm)과 북마크는 유지되지 않을 수 있습니다.
- Word 변환은 글자만 옮깁니다(표·그림은 제외).

## 구성

```
index.html · css/style.css · js/
  main.js    화면 전환·툴바·홈 카드·저장·파일 열기
  viewer.js  페이지 표시·확대/축소·편집 개체(텍스트/서명/펜 등)
  side.js    페이지·목차·검색 패널, 페이지 정리 화면
  tools.js   기능별 대화상자(변환·압축·보안·워터마크·OCR·서명 …)
  pdfcore.js PDF 처리(pdf-lib), 한글 글꼴 서브셋, OCR 글자 삽입
  doc.js     문서 상태·실행 취소 이력
vendor/      pdf-lib(+암호화), pdf.js, tesseract.js(+한국어/영어 데이터), JSZip, Noto Sans KR
sw.js · manifest.webmanifest · icons/   오프라인·설치(PWA)
```
