# PDF 공작소

PDF를 열고 · 고치고 · 서명하고 · 변환하고 · 줄이는 앱. 폰과 PC에서 같은 화면으로 쓰는 웹앱(PWA)이자 Windows 설치 앱입니다.
**모든 처리는 기기 안에서만 이루어집니다.** 파일이 서버로 올라가지 않고, 한 번 열어 두면 오프라인에서도 동작합니다.

- 웹 주소: https://gcode77.github.io/PDF
- 현재 버전: **1.1.0**

## 설치 · 실행

| 환경 | 방법 |
|---|---|
| **Windows (가장 쉬움)** | [Releases](https://github.com/GCODE77/PDF/releases/latest)의 `PDF-Gongjakso-Setup.exe`를 받아 더블클릭. 바탕화면·시작 메뉴 아이콘이 생기고, PDF 파일의 「연결 프로그램」으로도 쓸 수 있습니다. |
| 폰 · PC (웹앱 설치) | 위 웹 주소를 열고 앱 안의 「앱 설치」 버튼(또는 브라우저 메뉴의 「앱 설치 / 홈 화면에 추가」)을 누릅니다. 아이폰은 사파리의 공유 → 「홈 화면에 추가」. |
| 설치 없이 PC에서 | Releases의 `PDF-gongjakso-offline.zip`을 풀고 `실행.bat` 더블클릭 (파이썬 불필요) |

> 설치 파일은 코드 서명이 없어서 처음 실행할 때 Windows 보호 화면이 뜰 수 있습니다. 「추가 정보 → 실행」을 누르세요.
> 웹앱 설치와 오프라인 기능은 HTTPS 주소에서만 동작합니다.

## 업데이트

새 버전이 나오면 앱 위쪽에 알림 막대가 뜹니다(설치 앱은 Windows 알림창도 함께).

- 실행 3초 후, 6시간마다, 오래 두었다가 돌아왔을 때 자동으로 확인합니다. 메뉴의 **도움말 → 업데이트 확인**으로 직접 확인할 수도 있습니다.
- **설치 앱**: 「지금 업데이트」를 누르면 새 설치 파일을 내려받아 자동으로 설치하고 다시 실행합니다.
- **웹앱(폰·PC)**: 「지금 업데이트」를 누르면 바로 새 버전으로 새로고침됩니다.
- 「나중에」를 누르면 하루 동안은 같은 버전으로 다시 알리지 않습니다.
- 버전 정보는 이 저장소의 `version.json`(웹 주소로 배포)에서 읽습니다. 업데이트 내려받기는 이 저장소의 릴리스 주소만 허용합니다.

## 기능

- **편집·주석**: 텍스트 추가, 메모(스티커), 형광펜, 펜(손글씨), 이미지 삽입, 스탬프(승인됨·초안 등), 지우개(영역 가리기 → 모든 페이지 적용)
- **서명**: 직접 그리기 / 이름 입력 / 서명 사진 올리기(흰 배경 자동 제거), 기기에 저장해 재사용
- **페이지**: 끌어서 순서 변경, 삭제, 개별 회전, 복제, 빈 페이지 추가, 선택 추출, PDF 삽입, 파일 결합
- **변환**: PDF → 사진(PNG/JPG, 여러 장은 ZIP) · 텍스트(TXT) · Word(DOCX) / 사진 → PDF
  - 사진 → PDF: 번호 입력이나 끌어서 순서 지정, 이름순·날짜순·거꾸로 정렬, 회전, 카메라 촬영(폰), 열린 문서 뒤에 이어 붙이기
- **압축**: 가벼운 최적화 / 균형 / 최대 압축
- **보안**: 열기 비밀번호 + 인쇄·복사·편집 제한. 암호 PDF는 열 때 비밀번호를 입력하면 해제된 사본으로 열림
- **워터마크**: 글자·로고, 가운데/바둑판 반복. 이 앱이 넣은 워터마크와 표준 워터마크 주석은 자동 제거
- **배경 정리**: 스캔 문서의 그림자·누런 배경 제거(컬러/회색조/흑백), 미리보기 제공
- **문자 인식(OCR)**: 한국어+영어. 검색 가능한 PDF 만들기 / 글자만 추출
- **검색**: 문서 전체 검색(결과 목록·강조 표시), 목차(북마크) 보기

## 화면 구성 (Adobe Acrobat 구성을 참고)

- **홈**: 큰 「PDF 열기」 버튼, 왼쪽 메뉴(최근 · 별표 표시된 파일 · 파일 · 도구), 최근 파일 목록(썸네일·열린 시간·크기, 목록/격자 보기), 도구 카드, 위쪽 검색창(파일·도구 검색)
- **메뉴 막대(PC)**: 파일 · 편집 · 보기 · 창 · 도움말. 단축키가 함께 표시되고, 파일 메뉴에 최근 파일 5개가 나옵니다.
- **편집 화면**: 위쪽 도구 막대, 왼쪽 페이지·목차·검색 패널, 오른쪽 도구 목록, 아래쪽 확대/축소 막대. 오른쪽 위의 파란 **저장** 버튼은 항상 같은 자리에 있고, 편집 내용은 저장할 때 PDF에 합쳐집니다.
- **폰**: 아래 메뉴(페이지·검색·도구·홈), 두 손가락 확대/축소, 도구 목록은 아래에서 올라오는 시트
- **최근 파일·별표**: 이 기기(브라우저 저장소)에만 저장됩니다. 80MB가 넘는 파일은 목록에만 남고 다시 열 때 파일을 새로 고릅니다. 별표는 목록 정리 때 지워지지 않습니다.

| Ctrl + Z / Ctrl + Y | 실행 취소 / 다시 실행 |

## 알아둘 점

- 「균형·최대 압축」, 「배경 정리」, 암호 해제는 페이지를 이미지로 다시 만들기 때문에 글자 선택·검색이 사라집니다. 필요하면 이어서 「문자 인식(OCR)」을 실행하세요.
- 다른 프로그램이 문서 내용에 합쳐 넣은 워터마크는 자동 제거가 어렵습니다. 「지우개」로 가린 뒤 「모든 페이지에 적용」을 쓰세요.
- 페이지 복제·재구성 시 문서의 입력 양식(AcroForm)과 북마크는 유지되지 않을 수 있습니다.
- Word 변환은 글자만 옮깁니다(표·그림은 제외).

## 새 버전 내는 방법

1. 버전 번호를 올립니다: `js/update.js`의 `VERSION`, `version.json`의 `version`·`notes`, `desktop/package.json`의 `version`.
2. 코드를 `main`에 푸시합니다(GitHub Pages로 웹앱이 자동 배포되고, `sw.js`의 캐시 이름 `pdfgongjakso-vN`도 올려 두면 오래된 캐시가 정리됩니다).
3. `python desktop/build.py`로 설치 파일(`PDF-Gongjakso-Setup.exe`)을 만듭니다. 한글 경로 문제를 피하려고 임시 영문 폴더에서 빌드하며, Node.js와 Python(Pillow)이 필요합니다.
4. 새 태그로 GitHub 릴리스를 만들고 설치 파일과 ZIP을 올립니다. 이미 설치된 앱들이 다음 확인 때 알림을 받습니다.

```
vendor/       pdf-lib(+암호화), pdf.js(호환 빌드), tesseract.js(+한국어/영어 데이터), JSZip, Noto Sans KR

```
